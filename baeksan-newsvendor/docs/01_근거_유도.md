# 01 근거와 유도

대응 문항: 1번, 2번, 3번

진행 상황: 1번, 2번 정리 완료. 3번은 학습 후 작성.

## 문제 상황

- **결정:** 판매 시즌 전에 생산량을 한 번 정한다. 선택지는 1,000개, 2,000개, 3,000개다.
- **불확실한 것:** 수요. 1,000개(20%), 2,000개(50%), 3,000개(30%) 중 하나가 나온다.
- **순서:** 생산량 결정 → 수요가 드러남 → 판매 → 남은 물건 처분
- **목표:** 기대이익을 최대로 한다.

출처: 과제 안내문 02번 본문과 문제 조건. 같은 구조(수요가 불확실하고, 수요가 드러나기 전에 한 번만 주문하며, 남은 물건은 낮은 가격에 처분)를 MIT 자료는 신문팔이 문제(newsvendor problem)라고 부른다(MIT Newsvendor 노트 1쪽 "Characteristics of the problem").

## 이익 계산식

### 판매량과 남은 수량을 정하는 규칙

- 판매량 = min(생산량, 수요)
  - 수요가 생산량보다 적으면 수요만큼 팔린다.
  - 수요가 생산량보다 많아도 만든 만큼만 팔린다. 못 판 수요에 벌금은 없다.
- 남은 수량 = 생산량 − 판매량 (0 이상)

출처: 과제 안내문 02번 본문 "수요만큼 판매하되 재고가 부족하면 있는 만큼만 판매하고, 남은 제품은 모두 처분합니다", "품절 벌금, 고정비는 없으며"

### 이익 식

생산량을 Q, 수요를 D라고 하면

```
이익(Q, D) = p × min(Q, D) + s × (Q − min(Q, D)) − c × Q
```

| 기호 | 의미 | 값 | 단위 |
|---|---|---|---|
| p | 판매가격 | 10,000 | 원/개 |
| s | 처분가격 | 2,000 | 원/개 |
| c | 생산비 | 6,000 | 원/개 |
| Q | 생산량 | 1,000 / 2,000 / 3,000 | 개 |
| D | 수요 | 1,000 / 2,000 / 3,000 | 개 |

- 첫째 항: 판매 수입 (원/개 × 개 = 원)
- 둘째 항: 처분 수입
- 셋째 항: 생산비. 팔리든 안 팔리든 만든 개수만큼 든다.

값의 출처: 과제 안내문 02번 문제 조건. 판매 수입과 할인 처분 수입을 더하는 계산은 MIT Newsvendor 노트 5쪽 예제(판매 개수 × $80 + 남은 개수 × $40)와 같은 방식이다. 기호 p, c, s는 MIT 노트 1쪽의 표기(wholesale price w, salvage price s)를 참고했고, 생산 상황에 맞게 생산비를 c로 적었다.

## 기대이익

수요가 미리 정해지지 않으므로, 생산량마다 "같은 결정을 여러 번 반복하면 평균 얼마를 버는가"로 비교한다.

```
기대이익(Q) = Σ P(D = d) × 이익(Q, d)
            = 0.2 × 이익(Q, 1,000) + 0.5 × 이익(Q, 2,000) + 0.3 × 이익(Q, 3,000)
```

각 경우의 이익에 그 경우의 확률을 곱해 모두 더한다.

출처: 확률 가중합으로 기대수입을 구하는 방식은 MIT Newsvendor 노트 5쪽 예제("Expected Revenue" 열 = 확률 × 수입, 합계 "Total Expected Revenue")를 따랐다. 확률값은 과제 안내문 02번 문제 조건.

## 손실 확률

```
손실 확률(Q) = 이익(Q, d) < 0 인 수요 d의 확률을 모두 더한 값
```

- 손실 금액의 크기는 보지 않고, 손실이 나는지 여부만 본다. 손실의 크기는 기대이익에 반영된다.
- **손실의 기준:** 이익이 0보다 작을 때만 손실로 본다. 이익이 정확히 0원인 경우는 손실에 넣지 않았다. 과제 안내문이 손실을 정의하지 않아 직접 정한 해석이며, `문항_검토.md` 1번에 적었다.

## 베이즈 정리 (2번)

### 식

```
P(A | B) = P(B | A) × P(A) ÷ P(B)

P(B) = Σᵢ P(B | Aᵢ) × P(Aᵢ)     (Aᵢ가 서로 겹치지 않고 모든 경우를 빠짐없이 나눌 때)
```

출처: Wikipedia "Bayes' theorem", "Statement of theorem" 절. 두 번째 식(전확률 법칙)은 같은 절의 "Visual proof" 부분에 나온다.

### 이 과제에 대응시키면

A = "실제 수요가 d개", B = 받은 신호(S)

```
P(수요 = d | 신호 S) = P(신호 S | 수요 = d) × P(수요 = d) ÷ P(신호 S)
P(신호 S) = Σ_d P(신호 S | 수요 = d) × P(수요 = d)
```

| 식의 항 | 이름 | 이 과제에서 | 출처 |
|---|---|---|---|
| P(수요 = d) | 사전확률 (prior) | 신호를 보기 전 수요 확률 0.2 / 0.5 / 0.3 | 과제 안내문 02번 문제 조건 |
| P(신호 S \| 수요 = d) | 우도 (likelihood), 신호의 조건부확률 | "고수요"일 확률: 수요 3,000개일 때 0.8, 1,000·2,000개일 때 0.2 | 과제 안내문 02번 문제 조건 |
| P(신호 S) | 증거 (evidence), 주변확률 | 신호가 나올 전체 확률. "고수요" 0.38, "고수요 아님" 0.62 | 위 둘로 계산 |
| P(수요 = d \| 신호 S) | 사후확률 (posterior) | 신호를 본 뒤 고친 수요 확률 | 위 셋으로 계산 |

### 1,000번 세기와 식의 대응

`02_손계산.md`에서는 1,000번 장사한다고 보고 횟수를 셌다. 각 단계가 식의 한 부분이다.

| 손계산 단계 | 예: 수요 3,000개, "고수요" 신호 | 식의 부분 |
|---|---|---|
| 1,000번 중 수요별 횟수 | 1,000 × 0.3 = 300 | 1,000 × P(수요 = d) |
| 그중 신호가 나온 횟수 | 300 × 0.8 = 240 | 1,000 × P(신호 \| 수요 = d) × P(수요 = d) |
| 신호가 나온 횟수의 합계 | 40 + 100 + 240 = 380 | 1,000 × P(신호) (전확률 법칙) |
| 합계 중 비율 | 240 ÷ 380 = 0.632 | P(수요 = d \| 신호) |

1,000은 분자와 분모에 똑같이 곱해지므로 나눗셈에서 사라진다. 그래서 횟수로 센 결과와 식의 결과가 같다.

### 헷갈리기 쉬운 점: 80%와 63%

- P(고수요 | 수요 = 3,000) = 0.8: 수요가 3,000개**일 때** "고수요"라고 말할 확률 (과제 안내문 02번 문제 조건)
- P(수요 = 3,000 | 고수요) = 240 ÷ 380 = 0.632: "고수요"라고 **들었을 때** 수요가 3,000개일 확률

조건과 결과의 방향이 반대인 서로 다른 확률이다. 63%가 80%보다 낮은 이유는 수요가 적은 날(1,000번 중 700번)이 많아서, 그중 20%만 잘못된 "고수요"가 나와도 140번(40 + 100)이 섞이기 때문이다. "고수요" 380번 = 진짜 240번 + 잘못된 140번.

### 신호별 최적 생산량

```
E[이익(Q) | 신호 S] = Σ_d P(수요 = d | 신호 S) × 이익(Q, d)
최적 생산량(S) = E[이익(Q) | 신호 S]가 가장 큰 Q
```

1번의 기대이익 식에서 사전확률을 사후확률로 바꾼 것이다.

## 사용한 가정

과제 안내문 02번에 적힌 가정:

1. 생산은 시즌 전에 한 번만 하고 추가 생산은 없다.
2. 수요는 1,000개, 2,000개, 3,000개 세 값 중 하나이고 확률은 20%, 50%, 30%다.
3. 수요는 생산량과 무관하다.
4. 남은 제품은 개당 2,000원에 **모두** 처분된다.
5. 품절 벌금과 고정비는 없다.
6. 판단 기준은 기대이익 최대화다.

풀이하며 추가로 정한 해석:

7. 이익이 0원인 경우는 손실로 보지 않는다.
8. 가격과 비용은 생산량과 관계없이 일정하다(대량 할인 없음). 안내문에 개당 가격만 주어졌으므로 그대로 적용했다.
