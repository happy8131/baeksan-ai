# 01 근거와 유도

대응 문항: 1번, 2번, 3번

진행 상황: 1번 정리 완료. 2번, 3번은 학습 후 작성.

## 문제 상황

- **결정:** 판매 시즌 전에 생산량을 한 번 정한다. 선택지는 1,000개, 2,000개, 3,000개다.
- **불확실한 것:** 수요. 1,000개(20%), 2,000개(50%), 3,000개(30%) 중 하나가 나온다.
- **순서:** 생산량 결정 → 수요가 드러남 → 판매 → 남은 물건 처분
- **목표:** 기대이익을 최대로 한다.

출처: 과제 안내문 02번 본문과 문제 조건. 같은 구조(수요가 불확실하고, 수요가 드러나기 전에 한 번만 주문하며, 남은 물건은 낮은 가격에 처분)를 MIT 자료는 신문팔이 문제(newsvendor problem)라고 부른다(MIT Newsvendor 노트 1쪽 "Characteristics of the problem").

## 이익 계산식

### 판매량과 남은 수량을 정하는 규칙

- 판매량 = min(생산량, 수요)
  - 수요가 생산량보다 적으면 수요만큼 팔린다.
  - 수요가 생산량보다 많아도 만든 만큼만 팔린다. 못 판 수요에 벌금은 없다.
- 남은 수량 = 생산량 − 판매량 (0 이상)

출처: 과제 안내문 02번 본문 "수요만큼 판매하되 재고가 부족하면 있는 만큼만 판매하고, 남은 제품은 모두 처분합니다", "품절 벌금, 고정비는 없으며"

### 이익 식

생산량을 Q, 수요를 D라고 하면

```
이익(Q, D) = p × min(Q, D) + s × (Q − min(Q, D)) − c × Q
```

| 기호 | 의미 | 값 | 단위 |
|---|---|---|---|
| p | 판매가격 | 10,000 | 원/개 |
| s | 처분가격 | 2,000 | 원/개 |
| c | 생산비 | 6,000 | 원/개 |
| Q | 생산량 | 1,000 / 2,000 / 3,000 | 개 |
| D | 수요 | 1,000 / 2,000 / 3,000 | 개 |

- 첫째 항: 판매 수입 (원/개 × 개 = 원)
- 둘째 항: 처분 수입
- 셋째 항: 생산비. 팔리든 안 팔리든 만든 개수만큼 든다.

값의 출처: 과제 안내문 02번 문제 조건. 판매 수입과 할인 처분 수입을 더하는 계산은 MIT Newsvendor 노트 5쪽 예제(판매 개수 × $80 + 남은 개수 × $40)와 같은 방식이다. 기호 p, c, s는 MIT 노트 1쪽의 표기(wholesale price w, salvage price s)를 참고했고, 생산 상황에 맞게 생산비를 c로 적었다.

## 기대이익

수요가 미리 정해지지 않으므로, 생산량마다 "같은 결정을 여러 번 반복하면 평균 얼마를 버는가"로 비교한다.

```
기대이익(Q) = Σ P(D = d) × 이익(Q, d)
            = 0.2 × 이익(Q, 1,000) + 0.5 × 이익(Q, 2,000) + 0.3 × 이익(Q, 3,000)
```

각 경우의 이익에 그 경우의 확률을 곱해 모두 더한다.

출처: 확률 가중합으로 기대수입을 구하는 방식은 MIT Newsvendor 노트 5쪽 예제("Expected Revenue" 열 = 확률 × 수입, 합계 "Total Expected Revenue")를 따랐다. 확률값은 과제 안내문 02번 문제 조건.

## 손실 확률

```
손실 확률(Q) = 이익(Q, d) < 0 인 수요 d의 확률을 모두 더한 값
```

- 손실 금액의 크기는 보지 않고, 손실이 나는지 여부만 본다. 손실의 크기는 기대이익에 반영된다.
- **손실의 기준:** 이익이 0보다 작을 때만 손실로 본다. 이익이 정확히 0원인 경우는 손실에 넣지 않았다. 과제 안내문이 손실을 정의하지 않아 직접 정한 해석이며, `문항_검토.md` 1번에 적었다.

## 사용한 가정

과제 안내문 02번에 적힌 가정:

1. 생산은 시즌 전에 한 번만 하고 추가 생산은 없다.
2. 수요는 1,000개, 2,000개, 3,000개 세 값 중 하나이고 확률은 20%, 50%, 30%다.
3. 수요는 생산량과 무관하다.
4. 남은 제품은 개당 2,000원에 **모두** 처분된다.
5. 품절 벌금과 고정비는 없다.
6. 판단 기준은 기대이익 최대화다.

풀이하며 추가로 정한 해석:

7. 이익이 0원인 경우는 손실로 보지 않는다.
8. 가격과 비용은 생산량과 관계없이 일정하다(대량 할인 없음). 안내문에 개당 가격만 주어졌으므로 그대로 적용했다.
