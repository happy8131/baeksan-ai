## 전수 계산으로 손계산 재현

경우의 수가 유한하므로 모든 경우를 코드로 계산해 손계산과 비교합니다(과제 안내문 "과제 구성 원칙" 3. 수치 검증: "정확한 계산이면 전수 검증").

- 코드: `src/params.ts`(문제 조건), `src/profit.ts`(1번), `src/bayes.ts`(2·3번)
- 실행: `npm run exact` → 출력과 `results/exact.txt`
- 자동 비교: `npm test` → `tests/exact.test.ts` 12개 테스트 통과
- 입력: 생산비 6,000원, 판매가 10,000원, 처분가 2,000원, 수요 확률 0.2 / 0.5 / 0.3, a = 0.8

| 항목 | 손계산 | 코드 결과 | 차이 |
