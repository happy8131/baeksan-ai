## 실행 방법

Node.js 22.18 이상이 필요합니다.

```bash
npm install
npm test            # 손계산 값과 코드 결과 비교
```

검증 스크립트의 실행 명령, 입력값, 예상 결과와 실제 결과는 코드를 작성하면서 이곳에 추가합니다.

## 프롬프트 히스토리

- `prompts/prompt_history.csv`: 열은 작성시각(한국 시간), 도구, 프롬프트이며 프롬프트 하나가 한 행입니다.
- Claude Code의 `UserPromptSubmit` 훅(`../.claude/settings.json`)이 프롬프트를 보낼 때마다 `prompts/log-prompt.ts`를 실행해 자동으로 기록합니다.
- 훅이 놓친 프롬프트는 `npm run prompts:backfill`로 Claude Code 세션 기록의 시각과 내용을 그대로 옮깁니다.
- 주제를 고르는 과정(08번 검토 후 02번으로 변경)의 프롬프트도 포함되어 있습니다.
